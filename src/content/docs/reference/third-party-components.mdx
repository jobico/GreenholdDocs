import data from '../../../data/third-party-components.json';

export const usersOf = (id) => [...new Set(data.components.filter((c) => c.texts.includes(id)).map((c) => c.name))];

Greenhold uses third-party components.
This page lists each component once, with its version, its license, the address of its project and the Greenhold parts that use it.
The Manager shows the same list on its **Third-party components** page.

The list has {data.components.length} components.
The parts are: {data.parts.join(', ')}.
A component that two parts use in different versions has one row for each version.

The packages that build this documentation site are on the [Third-party notices](/third-party-notices/) page.
