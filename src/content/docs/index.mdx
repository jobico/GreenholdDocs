## What Greenhold is

Greenhold runs PowerShell and installs software on Windows computers.
It runs on a schedule or on demand.
You control it from a web console.
It works over your LAN or over the internet.
Agent computers need no open inbound port. Only the server accepts connections.

You host all parts of Greenhold.
The vendor runs no service for you.
