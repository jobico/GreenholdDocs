## What Greenhold is

Greenhold runs PowerShell and installs software on Windows computers.
It runs on a schedule or on demand.
You control it from a web console.
It works over your LAN or over the internet.
No computer needs an open inbound port.

You host all parts of Greenhold.
The vendor runs no service for you.

## Two products

<CardGrid>
  <Card title="Dispatch" icon="rocket">
    Dispatch sends signed work to your computers.
    An administrator signs each Order.
    The agent on each computer checks the signature before it runs the work.
  </Card>
  <Card title="Library" icon="open-book">
    Library holds the software that Dispatch can install.
    You publish packages to your own storage.
  </Card>
</CardGrid>
